# Кроко — онлайн-крокодил

Одна общая комната «Простые». Игроки заходят по ссылке, один становится художником, остальные угадывают слово в чате. Художник меняется после каждого угаданного слова или по таймеру.

## Как это работает

- Статический фронтенд: `index.html`, `game.html`, `styles.css`, `app.js`, `home.js`, `game.js`.
- Онлайн-синхронизация через MQTT/WebSocket (`mqtt.min.js`).
- Общее состояние комнаты хранится в retained-сообщении `krokotest/simple/v1/state`.
- Присутствие игроков — в `krokotest/simple/v1/presence/<id>` с last-will на выход.
- Живые штрихи художника — в `krokotest/simple/v1/draft/<id>`.

Сейчас используется публичный тестовый брокер HiveMQ `wss://broker.hivemq.com:8884/mqtt`. Он не требует регистрации, поэтому игра работает сразу после публикации на GitHub Pages. Для постоянной нагрузки замените адрес брокера в `app.js` на свой бесплатный HiveMQ Cloud / EMQX / Ably и при необходимости добавьте авторизацию.

## Локальный запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
```

Откройте `http://localhost:8080/`. Две вкладки с `game.html` должны видеть друг друга через MQTT.

## Публикация

Репозиторий уже настроен для GitHub Pages:

1. `Settings → Pages`.
2. `Source`: `Deploy from a branch`.
3. Branch: `main`, folder: `/ (root)`.
4. Save.

Сайт будет доступен по адресу `https://smorvel.github.io/krokotest/`.

## Правила игры

- У всех игроков общий холст и общий чат.
- У художника слово видно, у остальных — замаскировано; кнопка «подсказка» показывает первую букву.
- Время раунда — 90 секунд.
- Первый угадавший получает 10 очков, и начинается новый раунд с новым художником.
- Кнопки кистей, ластика, пипетки, цвета фона и отмены доступны только художнику.
