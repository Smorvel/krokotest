# Кроко — онлайн-крокодил

Статический сайт с онлайн-синхронизацией через MQTT/WebSocket. Игроки по общей ссылке попадают в одну комнату, видят общий холст, чат, очередь художников и очки.

## Ссылки

- Сайт: https://smorvel.github.io/krokotest/
- Игра: https://smorvel.github.io/krokotest/game.html
- Личный кабинет: https://smorvel.github.io/krokotest/cabinet.html

## Возможности

- Одна системная комната «Простые» и создание своих комнат со ссылкой для всех.
- При создании комнаты и в настройках можно выбрать несколько словарей: слово каждого раунда берётся случайно из одного из выбранных словарей, недавние повторы исключаются.
- Смена набора словарей и времени раунда применяется только со следующего раунда: текущий рисунок не сбрасывается.
- Слова-фразы угадываются по отдельным словам или целиком, в любом порядке. Частичное угадывание помечается в чате сообщением «Слово … присутствует в загадке!», раунд завершается только после всей фразы.
- Время раунда по умолчанию 5 минут; создатель может вручную поставить от 0 до 60 минут. `0` — без ограничений.
- Если время вышло, а угадывающих в комнате нет, раунд ждёт их. Когда игрок заходит на нулевом времени, раунд автоматически продлевается на 60 секунд.
- Подсказка появляется автоматически в чате за 10% времени до конца раунда; отдельной кнопки нет.
- Сообщения чата от предыдущего раунда серые. Художник и создатель могут ставить лайк/дизлайк сообщениям, чтобы показать направление поиска.
- Очередь рисования: новый игрок добавляется в конец и не перехватывает ход у текущего художника.
- Создатель комнаты может менять словари, время раунда и удалять участников; чёрный список показывает только имена, без IP. Создатель не может быть заблокирован.
- Бан использует ID профиля и устойчивый отпечаток браузера: новая вкладка/профиль на том же устройстве не обходит бан. Это клиентская защита без бэкенда и при желании её можно обойти подменой отпечатка.
- Свои словари создаются в личном кабинете или прямо в комнате и попадают в общее состояние раунда, поэтому доступны всем игрокам.
- Кисти всегда видны слева, по одной в строке: стандартная, мягкая Photoshop-подобная, планшетная (медленнее — толще), фигурная (квадрат → круг → полоса), заливка, разделитель и ластик.
- Пипетка перенесена к цветам. Размер и прозрачность — кружки: тяните вверх, чтобы увеличить, вниз — уменьшить; клик по кружку открывает палитру. Подписи показывают пиксели и проценты.
- Палитра под холстом оформлена кляксами, есть квадрат цвета фона и редактор своих цветов.
- Масштаб холста меняется кнопками «− / Вписать / +». Нативный курсор на холсте скрыт, вместо него показывается круг кисти требуемого размера.
- Есть переключатель «Плавность» с усиленным сглаживанием линий.
- Живой штрих рисуется по кадрам через отдельный слой и остаётся видимым от начала до отпускания, у других игроков не мигает и не теряет начало.
- Холст не затемняется, когда рисует другой игрок. Цвет фона сохраняется между раундами.
- После правильного ответа показывается короткая пауза с анимацией, затем ход переходит следующему художнику.
- Отмена штриха (`Ctrl+Z`), очистка холста, таймер, вкладки «Чат», «Игроки» и «Настройки».
- Весь интерфейс использует Google Roboto; размер текста чата — 14 px.

## Технически

- MQTT-брокер: `wss://broker.hivemq.com:8884/mqtt` (публичный тестовый, без регистрации).
- Корень топиков: `krokotest/v2/rooms/<slug>/...`.
- `meta` — название комнаты, создатель, выбранные словари и их слова.
- `state` — общее состояние: очередь, ход, штрихи, чат, реакции, баны, история слов и флаг подсказки.
- `presence/<id>` — присутствие с last-will на выход.
- `draft/<id>` — живой штрих художника, публикуется частями до отпускания указателя.

Для постоянной нагрузки замените публичный брокер в `app.js` на приватный HiveMQ Cloud, EMQX или Supabase Realtime и добавьте авторизацию. Без сервера невозможно настоящего IP-бана: текущая защита надёжна для честных игроков, но злоумышленник со знанием топика может подменить клиентские данные.

## Локальный запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
```

Откройте `http://localhost:8080/`. Две вкладки или два браузера на разных портах должны видеть друг друга через MQTT.
